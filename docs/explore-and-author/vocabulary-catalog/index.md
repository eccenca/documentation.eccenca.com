# Vocabulary Catalog

!!! warning "Removed module"

    The Vocabulary Catalog module is not part of eccenca Corporate Memory 26.2 and higher.
    It is superseded by the [Marketplace](../../distribution/marketplace/index.md), where vocabularies and ontologies are delivered as Marketplace Packages.

    Use the Marketplace to browse and install vocabularies, and the `package` command group of cmemc instead of the deprecated `vocabulary install` and `vocabulary uninstall` commands.

This page is kept so that links from the release notes of older versions stay intact.
